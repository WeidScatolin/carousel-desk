# carousel-desk

Automação de um Instagram de tecnologia: scraping de temas, geração de
carrosséis editoriais por IA, aprovação em duas etapas via dashboard kanban
e publicação diária automática pela API oficial do Instagram.

Uso pessoal — não é um SaaS.

Design completo em
[`docs/superpowers/specs/2026-09-02-carousel-desk-design.md`](docs/superpowers/specs/2026-09-02-carousel-desk-design.md).
